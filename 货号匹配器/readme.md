# 货号匹配器 - 使用说明

## 一、这个项目是干什么的

把「含货号的表格」自动匹配成「完整商品导入表」。

- 数据源为 SAP 导出表（A006-货号统计），输出严格按商品导入模板的 34 列布局，可直接用于上传。
- 本工具只做「货号匹配」——把货号对应的 SAP 商品信息填进模板。
- 商品分类的纠错/自动分类功能已移除，模板里的 `产品分类 / 二级 / 三级分类` 直接取自 SAP 原值，不再做修正或核对。

## 二、项目结构

```
货号匹配器/
├── scripts/
│   └── generate_matched.py    主脚本：货号匹配 SAP（Python）
├── 数据源/                     数据文件放这里
│   ├── A006-货号统计（全部）.xlsx   SAP 导出表（更新后直接替换同名文件）
│   └── 商品导入模板.xlsx            模板（一般不用动）
├── 输入/                      把要匹配的货号表放这里（或用拖入方式，不限位置）
├── 输出/                      ★交付文件都在这里：
│   └── 货号匹配结果.xlsx          匹配结果（34 列上传格式，含公式）
├── 商品匹配.bat               启动器：把货号表拖到它上面即自动出表
└── readme.md                  本说明
```

> 依赖与环境由根目录统一管理（见根 README 第〇节）：
> - `pyproject.toml` / `uv.lock` 锁定依赖；`.venv` 由 `uv sync` 生成，不进版本库。
> - 不再使用本目录旧的 `setup.bat` / `requirements.txt`（已删除）。

## 三、日常使用（单步）

双击项目文件夹里的 `商品匹配.bat`，或把货号表拖到它上面：

1. 货号匹配 SAP，输出 `输出\货号匹配结果.xlsx`
2. SAP 里没有的货号，结果表的「未匹配货号」sheet 会列出，对应行只有货号、其余留空
3. 直接在「匹配结果」/「未匹配货号」sheet 对应行补充信息（品名/条形码/采购单价/供应商），保存后重跑即可

命令行方式（可选，用根目录的 `.venv`）：

```bat
..\..\.venv\Scripts\python.exe scripts\run_pipeline.py match "货号表.xlsx"
..\..\.venv\Scripts\python.exe scripts\run_pipeline.py            :: 用默认 输入\货号信息.xlsx
```

## 四、换电脑 / 从仓库全新拉取

整个「货号匹配器」目录连同根项目一起拷贝或 `git clone` 即可，然后：

1. 在根目录（product-data-toolkit）执行 `uv sync`，自动创建 `.venv` 并安装全部依赖（需联网）。
2. 确认 `数据源` 文件夹里有 SAP 导出表和模板（没有就从原电脑拷过来，或更新数据）。
3. 之后即可按上面的流程使用。

> 【重要】`.venv` 文件夹不要拷贝，它在每台电脑上由 `uv sync` 各自重建（受根 `.gitignore` 忽略）。

## 五、输入表格式约定

- 必须有表头，且某一列表头含「货号」二字（找不到就取第 1 列）。
- 可选：如果有一列表头含「客户」，会自动按客户拆成多个 sheet。
- 重复货号会自动去重。

## 六、输出表列规则（已按公司要求固化）

- 批发价格(J)、是否打折(Y)、品牌(Z)：保留为实时 Excel 公式，打开自动计算。
- 销量(V)=100、币种(X)=CNY、最低起订量(W)=装箱量、产品属性(AC)=产品材质。
- 供应商编码(AF)=SAP 首选供应商、供应商名称(AG)=SAP 业务伙伴名称。
- 标签(AA)、AH 列不填。
- 产品分类/二级物料分类/三级物料分类：直接取 SAP 原值。
- 未匹配到的货号会单独列在「未匹配货号」sheet 里。

## 七、常见问题

- **结果文件被占用无法保存？** 先关闭 Excel 里打开的旧结果文件再重跑。
- **找不到 SAP 数据源？** 把 `A006-货号统计（全部）.xlsx` 放进 `数据源` 文件夹。
- **提示"未检测到当前商品"的货号？** 先跑一次匹配，未匹配清单会列出这些货号，可导出该清单核对货号是否正确。
- **跑的时候窗口像卡住了？** SAP 大文件首次解析需十几秒至几十秒（后台有进度打印），之后会自动缓存，再跑就几秒。
